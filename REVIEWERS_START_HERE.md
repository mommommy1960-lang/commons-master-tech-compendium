# Reviewers Start Here

The Commons Master Tech Compendium is an index and archive for the Initiative's research, governance, simulations, and proposed technology.

## Review focus

Check provenance, evidence labels, licensing, dependency links, version history, and separation between tested software, proposals, and speculation.

## Evidence boundary

Archive language is not evidence of physical operation. Each claim must be evaluated against the source artifact and its tests.

Read [SECURITY.md](SECURITY.md) and [CODEOWNERS](.github/CODEOWNERS).
