# Commons Release Gate

No repository may be described as production-ready, deployed, certified, or sellable until every applicable gate is evidenced.

## Required gates

1. Scope and user problem are documented.
2. Claims match the evidence level.
3. License and third-party obligations are reviewed.
4. Reproducible build and installation instructions exist.
5. Unit and adversarial tests pass in a clean environment.
6. Hosted CI executes actual steps and exposes logs.
7. Security and privacy threat models are reviewed.
8. Secrets, credentials, and personal data are absent from releases.
9. Operational monitoring, rollback, support, and incident procedures exist.
10. A named human approves the release record.
11. A versioned artifact and checksums are produced.
12. Any physical, medical, financial, aerospace, or safety-critical claims receive qualified independent review.
